# Learning Curriculum: Science & Physics Simulations

Interactive, production-ready educational web modules designed for high school science students.

## 📚 Curriculum Modules

### Grade 10: Physics
- **[Atmospheric Light Scattering](./grade-10/physics/physics-light-scattering/)**
  - **Live Simulation**: [https://jayakrishnankk.github.io/grade-10-physics-light-scattering/](https://jayakrishnankk.github.io/grade-10-physics-light-scattering/)
  - **Directory**: [`grade-10/physics/physics-light-scattering/`](./grade-10/physics/physics-light-scattering/)
  - **Key Concepts**: Rayleigh Scattering ($I \propto 1/\lambda^4$), daytime blue sky, golden sunset geometry, zero atmosphere conditions, and interactive ROYGBIV wavelength exploration.
  - **Documentation**: Includes [`README.md`](./grade-10/physics/physics-light-scattering/README.md) and [`PROMPT.md`](./grade-10/physics/physics-light-scattering/PROMPT.md).

## 🚀 Running Locally

You can open any simulation file directly in your browser:
```bash
open grade-10/physics/physics-light-scattering/index.html
```

Or start a local server from the repository root:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000/grade-10/physics/physics-light-scattering/`.
